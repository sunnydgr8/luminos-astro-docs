Product badges appear on product cards (sale savings, sold out, and custom labels). Custom badges support colors, auto text contrast, and optional icons.

When finished, a product card can look like this:

![Glow Eye Wand product card with vertical New, Popular, and Save badges](/images/product-badges/06-storefront-result.png)

*Custom labels + sale savings on a product card (vertical badges enabled).*

<a class="jump-link" href="#quick-checklist">Jump to checklist</a>

## Theme settings

Open **Online Store → Themes → Customize → Theme settings → Badges**.

![Theme settings Badges panel with custom labels and vertical badges highlighted](/images/product-badges/00-theme-settings-badges.png)

*Turn on custom labels (and vertical badges if you want the ribbon look).*

| Setting | What it does |
| --- | --- |
| Position on cards | Top left, top right, or bottom left |
| Show sold out badge | Shows when the product is unavailable |
| Show sale savings badge | Shows when compare-at price is higher than price |
| Savings display | Percent (`Save 25%`), amount (`Save $10`), or “Sale” label |
| Show custom labels | Turns on metafield / metaobject custom badges |
| Show badges vertically | Rotates badge text like a side ribbon |
| Font / font size / text case | Typography for badge text |
| Sale / sold out colors | Under theme **Colors** settings for badge schemes |

## Automatic badges

These need **no metafields**:

1. **Sale** — product (or variant) has a compare-at price above the selling price.
2. **Sold out** — product is unavailable and “Show sold out badge” is enabled.

## Custom badges (two methods)

Use **one** method per store (prefer metaobjects; parallel lists are the fallback).

### Method 1 — Metaobjects (recommended)

Best when you want a label, background color, optional text color, and optional icon per badge.

#### 1. Open Metaobjects and add a definition

In Shopify Admin go to **Settings → Custom data** (or **Metafields and metaobjects**). Under **Metaobject definitions**, click **Add definition**.

![Shopify settings Custom data with Add definition highlighted](/images/product-badges/01-settings-add-definition.png)

*Settings → Metafields and metaobjects → **Add definition**.*

#### 2. Add the product badge fields

Create a definition (for example name **Product badge**, type/handle `product_badge`) with these fields. **Keys must match exactly:**

![Product badge metaobject fields with required label and background highlighted](/images/product-badges/02-metaobject-fields.png)

| Field | Key | Type | Required |
| --- | --- | --- | --- |
| Label | `label` | Single line text | Yes |
| Background | `background` | Color | Yes |
| Text color | `text_color` | Color | No |
| Icon | `icon` | File / Image | No |

:::tip
Leave **Text color** empty to let LuminOS pick white or dark text automatically (dark text only on very light backgrounds).
:::

#### 3. Enable storefront access

On the metaobject definition, open **Metaobject options** and turn on **Storefronts API access** (Read).

![Storefronts API access toggle highlighted on metaobject options](/images/product-badges/04-storefront-access.png)

*Without storefront read access, badges will not appear on the storefront.*

#### 4. Add a product metafield

**Settings → Custom data → Products → Add definition**

![Product metafield definition for custom.product_badges](/images/product-badges/03-product-metafield.png)

| Setting | Value |
| --- | --- |
| Name | Product badges |
| Namespace and key | `custom.product_badges` |
| Type | **List of metaobjects** → your Product badge type |

#### 5. Assign badges on a product

Open a product → **Product badges** metafield → add entries (for example New, Popular). Set background colors; optionally set text color or icon.

### Method 2 — Parallel lists

Use when you only need text + background colors (no icons).

#### Create two list metafields on Products

| Name | Namespace and key | Type |
| --- | --- | --- |
| Badges | `custom.badges` | List of single line text |
| Badge colors | `custom.badge_colors` | List of color |

Optional: `custom.badge_text_colors` (list of color).

#### Fill them in the same order

![Parallel lists custom.badges and custom.badge_colors matched by index](/images/product-badges/05-parallel-lists.png)

*Index 1 pairs with index 1, and so on.*

Example:

| Index | `custom.badges` | `custom.badge_colors` |
| --- | --- | --- |
| 1 | New | `#e11d48` |
| 2 | Popular | `#dcfce7` |
| 3 | Limited | `#9f1239` |

Also supported: `theme.label` + `theme.label_colors` (+ optional `theme.label_text_colors`).

## Text contrast

If text color is blank:

- **Very light** backgrounds → dark text (`#111111`)
- All other backgrounds (red, maroon, blue, etc.) → white text

You can still set an explicit text color on the metaobject or via `custom.badge_text_colors` to override.

## Vertical badges

Enable **Show badges vertically** in Theme settings → Badges. Badges stack as tall ribbons with rotated text. Works best with **Top left** or **Bottom left** position.

## Quick checklist

1. Theme settings → Badges → enable the badge types you need.
2. For custom labels: create metaobjects **or** parallel list metafields.
3. Turn on storefront access for metaobjects.
4. Fill values on products.
5. Preview a collection or search results grid.
