This guide walks through creating a **mix and match** page from scratch. Shoppers pick any products from your pool, fill a sidebar, and unlock tier discounts. Cart lines use `_lumin_bundle_*` properties. Real checkout discounts need the [Lumin Discount App](/guides/lumin-discount-app).

<a class="jump-link" href="#quick-checklist">Jump to checklist</a>

## What you’ll build

1. A page that uses the **Lumin Bundle Builder** section.
2. **Bundle tier** blocks (for example 5 / 7 / 12 items).
3. Optional **Category** blocks so products appear in tabs.
4. The Discount App so the % off applies at checkout.

When finished, the storefront looks like this:

![Finished bundle builder on the storefront](/images/mix-and-match-bundles/01-bundle-overview.png)

*Left: product grid. Right: “Your bundle” sidebar with tiers and empty slots.*

## Before you start

- LuminOS theme installed and published (or a development theme).
- A **Page** in Shopify Admin (Online Store → Pages), or use the included **bundle** page template.
- Products you want in the pool, ideally already in collections.

## 1. Open the theme editor on your page

1. In Shopify Admin go to **Online Store → Themes**.
2. On LuminOS, click **Customize**.
3. At the top of the editor, open the page selector and choose your **bundle** page (or the template you want).
4. You should see the page preview on the right and the section list on the left.

:::tip
LuminOS ships with a **page.bundle** template. Duplicate it if you want a safe copy before editing.
:::

## 2. Add the Lumin Bundle Builder section

1. In the left sidebar, scroll to the bottom of the section list.
2. Click **Add section**.
3. Search for **Lumin bundle builder** (or browse the list).
4. Click it once to add it to the page.
5. Click **Save**.

![Add the Lumin bundle builder section](/images/mix-and-match-bundles/10-add-section.png)

*Theme editor → Add section → choose **Lumin bundle builder**.*

### Set the heading text

With the section selected, find these settings and fill them in:

| Setting | Example |
| --- | --- |
| Heading (products area) | `Choose your products` |
| Subheading | `Add products to build your bundle` |
| Show all | `Show all` (supports bold / italic / link) |

## 3. Add Bundle tier blocks

Tiers tell shoppers how many items unlock each discount. You add them as **blocks** inside the section.

### How to add a block

1. Click the **Lumin bundle builder** section in the left sidebar so it is selected.
2. In the section’s block list, click **Add block**.
3. Choose **Bundle tier**.
4. Repeat for each discount level (for example three tiers).

![Add a Bundle tier block](/images/mix-and-match-bundles/11-add-tier-block.png)

*Click **Add block**, then pick **Bundle tier**.*

### Fill in each tier

Click a Bundle tier block and set:

| Setting | Example | What it does |
| --- | --- | --- |
| Quantity | `5` | How many products this tier needs |
| Discount % | `20` | Percent off shown in the UI |
| Top label | `[n] Items` | `[n]` becomes the quantity |
| Bottom label | `[%] off` | `[%]` becomes the discount |

![Bundle tier settings](/images/mix-and-match-bundles/12-tier-settings.png)

*Example: 5 items for 20% off.*

:::note
Suggested starter tiers: **5 / 20%**, **7 / 25%**, **12 / 30%**. Keep labels short so they fit in the sidebar.
:::

On the storefront, tiers appear at the top of the sidebar:

![Sidebar with tiers and progress](/images/mix-and-match-bundles/05-sidebar-filled.png)

*Shoppers pick a tier, then fill the slots until the progress bar is complete.*

## 4. Add your products

You have two options.

### Option A — Simple pool (fastest)

1. Select the **Lumin bundle builder** section (not a block).
2. Under **Products**, set **Source** to **Collection** or **Product list**.
3. Choose the collection, or pick products one by one.
4. Adjust **Max products** and turn on **Hide sold-out** if you want.

### Option B — Category blocks (tabs)

Use this when you want filter tabs such as Skincare / New / Bags.

1. Select the section → **Add block** → **Category**.
2. Open the new Category block.
3. Set **Title** (inline rich text — you can bold words).
4. Choose a **Collection**, and/or pick **Products**.
5. Set **Max products** for that group.
6. Add more Category blocks for each tab.

![Add a Category block](/images/mix-and-match-bundles/13-add-category-block.png)

*Add block → **Category**.*

![Category block settings](/images/mix-and-match-bundles/14-category-settings.png)

*Title + collection (or products) + max products.*

:::caution
When Category blocks exist, they replace the simple collection / product list above. Put every product you want to sell inside a category.
:::

![Product cards](/images/mix-and-match-bundles/04-product-cards.png)

## 5. Style cards and colors

Still in the section settings:

1. Open **Product cards**.
2. Set **Card size desktop** to Small / Medium / Large (controls card width, not a fixed column count).
3. Set **Card size mobile** to Small or Large.
4. Pick image ratio, corner radius, and fonts.
5. Adjust colors for the section background, sidebar, buttons, and accents.
6. Enable **Show variant picker** if shoppers must choose a size/color before adding.
7. Click **Save**.

## 6. Connect the Discount App

The theme shows the discount labels, but Shopify only applies the money off when the app is installed.

1. Install the [Lumin Discount App](/guides/lumin-discount-app).
2. Enable discounts for LuminOS mix & match / `_lumin_bundle_*` line properties.
3. Place a test order in a development store and confirm the discount appears at checkout.

Theme **Cart** settings can also style the mix & match header in the [cart drawer](/guides/cart-drawer).

## 7. Test like a shopper

1. Open the page on the storefront (or the theme editor preview).
2. Click a category tab (optional).
3. Choose a tier (for example 5 items / 20% off).
4. On a product card, pick a variant if needed, then click **Add to bundle**.
5. Fill enough slots for the tier.
6. Click **Add bundle**.
7. Check the cart drawer — lines should show with bundle properties.

![Shopper adding products into the bundle](/images/mix-and-match-bundles/02-bundle-with-items.png)

*Filled slots, progress toward the tier, and Add bundle button.*

## Quick checklist

<a id="quick-checklist"></a>

- [ ] Page / template opened in the theme editor
- [ ] **Lumin Bundle Builder** section added
- [ ] At least one **Bundle tier** block with quantity + discount %
- [ ] Products added via pool **or** Category blocks
- [ ] Card size and colors checked on desktop and mobile
- [ ] Lumin Discount App installed and enabled
- [ ] Test: add products → cart → checkout discount

## Tips for beginners

- Save often in the theme editor.
- Start with **one** category and **two** tiers, then expand.
- If tabs do not appear, make sure each Category block has at least one available product.
- If checkout has no discount, the Discount App is missing or not enabled — the UI alone does not discount.
- Full setting list: [Lumin Bundle Builder](/sections/lumin-bundle-builder).
